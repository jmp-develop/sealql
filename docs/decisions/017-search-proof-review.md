# 017 — 검색 도장 판정의 반복 비용과 검토 반영

상태: 채택, 2026-09-29. [015](015-database-search-proofs.md)의 판정 구현을 보완한다. 저장 형식, 키 유도, AAD와 공개 연산 의미는 그대로다.

## 결정

128칸 이하 도장 배열은 내장 C 탐색을 한 번 쓰고, 큰 배열은 이진 탐색한다. 순수 PL/pgSQL 이진 탐색은 짧은 값에서 퇴행했고, 이진 탐색 뒤 마지막16칸만 C로 찾는 방식보다 이 분기가 단순하고 빨랐다. 이 상수는 내부 탐색 전환점이며 사용자 결과·작업 상한이 아니다.

contains/starts/ends의 각 창은 등장순번과 마지막 위치를 호출 안에서 유지하고 앞으로만 진행한다. 첫 창은 스칼라 커서, 나머지 창은 배열 커서를 쓴다. 순번마다 정렬된 도장을 조회하며, 발견한 위치가 NULL·범위 밖이거나 앞선 순번보다 작으면 오류를 낸다. 필요한 위치를 찾으면 즉시 다음 창으로 진행하고 첫 완전 일치에서 종료한다.

LIKE는 필요한 조각별 위치를 한 번 만들어 평평한 정수 배열과 시작·끝 인덱스로 보관한다. 패턴도 정수 프로그램으로 전달하여 JSON 생성과 재파싱을 없앤다. literal run은 이미 구한 목록 중 가장 짧은 목록에서 시작점을 열거하고, 나머지 창의 전진 커서로 교차 확인한다. `%`/`_`의 위치 전이는 유지한다. 기존 내부 JSON 인자 함수는 `extraMigrationSql`이 제거하므로 설치 뒤 새 검색 코드를 사용한다.

공백 제거는 토큰·도장·평문 판정이 같은 함수를 사용한다. count는 알려지지 않은 최상위 옵션을 일괄 거부한다. 201행 이상 페이지, 최상위 OR의 fallback, keyset 이어받기, 긴 contains/LIKE 근접 불일치와 손상 위치를 자동 시험한다. postgres-js도 Node pg·local workerd pg와 같은 실제 DB 흐름 시험에 포함한다.

## 근거

[검토 반영 보고](../../bench/results/2026-09-29-r9-review/report-ko.md)에 최종 탐색 방식, 이전 제품 대비 쓰기 비용, 대표 8조건, 긴 반복 값, EXPLAIN 및 게이트 출력을 보존한다. 예열 2회와 교차 7회 중앙값을 사용하며, 시험 제한 시간으로 중단한 이전 함수에는 중앙값을 주장하지 않는다.

## 기각안

48/52바이트 한 블록에 한정한 순수 JS SHA-256 후보는 NIST CAVP 해당 길이 벡터와 Node 독립 대조를 통과했다. 고정 64라운드이며 비밀 바이트에 따른 분기·인덱스는 없지만, JavaScript 런타임의 일정 시간 실행을 보장하는 근거는 아니다. insert 개선 11.4%, reindex 개선 10.1%로 사전 조건인 30%에 못 미쳐 **채택하지 않는다**. 제품은 WebCrypto를 유지하며 후보와 측정은 벤치에만 보존한다. 이 시험은 CAVP 인증이 아니다.
