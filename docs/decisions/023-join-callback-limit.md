# 023 — JOIN 콜백 limit의 입력 기반 타입

2026-09-29.

## 결정

`sealed.search` 호출 옵션이 필수 `limit: number`를 가지면 콜백의 `limit`는 `number`다. 생략하거나 선택적 `limit`를 전달하면 `number | undefined`를 유지한다. 제네릭 콜백 문맥과 필수 속성에 대한 오버로드로 표현하고 런타임 코드는 바꾸지 않는다. 콜백은 페이지 크기와 다른 batch를 받을 수 있으므로 숫자 리터럴 타입으로 좁히지 않는다.

## 근거

유한 페이지의 JOIN 콜백에서 Drizzle `.limit(limit)`를 직접 호출할 수 없던 타입 오류를 해결한다. 숫자·생략·선택적 속성·undefined 가능한 값과 기존 넓은 콜백 타입 및 복호화 반환 타입을 `test/standard-types.ts`에서 확인한다. [검증 기록](../../bench/results/2026-09-29-join-limit/report-ko.md)에 전체 게이트와 런타임 JS 동일성 결과를 둔다.

## 기각안

모든 콜백의 limit를 number로 바꾸면 무제한 검색을 잘못 표현한다. 런타임 기본 limit를 추가하거나 사용자가 단언을 쓰도록 강제하지 않는다.

## 대체 관계

013의 JOIN 공개 타입만 개선한다. 014의 무제한 검색 및 기존 배치·커서·SQL 동작은 유지한다. 저장물·전송물·보안 성질은 변하지 않는다.
