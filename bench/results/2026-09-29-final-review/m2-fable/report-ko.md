# 마지막 검토 — 검색 가능 암호화 공격 문헌 조사 + 공격 경로 전수 목록 (m2-fable, 2026-09-29)

대상 구조(최종 코드 7c14bda): 칸마다 (a) 결정적 16비트 절단 HMAC 조각 토큰(인접 2글자 + 시작·끝 + 건너뜀, scope 32비트 접두, GIN), (b) 행별 salt 16 B + 위치 도장 `SHA256(k_piece ‖ salt ‖ 등장순번)[:8]` + 평문 위치 배열 + 정규화 길이 n, (c) 정확 일치 도장 `SHA256(k_value ‖ salt)[:8]`; 질의 시 조각 키를 DB로 보내 PL/pgSQL이 후보 행마다 도장을 재계산. 본문 AES-256-GCM(논의 제외). 확신 수준: **확실**(문헌 수치·우리 실측 있음) / **추정**(구조 논증) / **모름**(문헌·실측 없음).

이 문서는 즉시 수정 요청이 아니다. 목적은 "우리 시뮬레이션을 어디까지 강화할 수 있는가"의 지도다. 코드·DB 작업 없음.

## A. 알려진 공격 문헌과 우리 구조에의 적용 (출처 링크 포함)

수집 노트(공격 문헌·시스템·측면 채널)는 비공개 작업 폴더에 있다. 이번 세션은 웹 검색 API 예산이 소진돼 1차 출처 직접 fetch만 가능했다 — "이번 세션 재확인"이라고 적은 것만 원문을 다시 열어 확인했고, 나머지 수치는 앞선 미션(2026-09-28 MongoDB 해부 노트와 그 논문 발췌)에서 원문으로 확인한 값이다.

기호 — 적용: ○ 우리 구조에 그대로 적용 / △ 조건부 / ✕ 해당 없음. 시험: 함(근거) / 부분 / 안 함.

### A9. 판정 — 시험한 것과 겹치는 것, 안 한 것 중 위험이 큰 것
| 순위 | 미시험(또는 부분) 공격 | 왜 위험한가 | 필요한 시험(B 목록) |
|---|---|---|---|
| 1 | 선택 원문 주입(A2, Zhang–Katz–Papamanthou) | 아는 행 비율을 공격자가 정함 → 0.01–0.1% 결론 무효 가능 | B2-9 (r9-impl) |
| 2 | 아는 질의 10개·볼륨만으로 질의 복원(A1: Damie 85%, Blackstone 70%, Jigsaw 90%) | 우리 관찰 시험은 "검색어 원문을 다 안다"는 강한 가정 아니면 "키만"의 약한 가정 두 극단만 | B3-12 변형 + B3-14 |
| 3 | 그래프 정합·패턴 마이닝(A3, PPRL Bloom 공격·Shadow Nemesis) | 아는 행 0에서 라벨 생성; 16비트 버킷 = Bloom 비트 | B1-3 |
| 4 | 위치 이어 붙이기 + 유도 질의(A4) | 최종 형식 고유 채널; 문헌 19–98% | B3-16 강화 |
| 5 | 정확 길이·n·공백 수(A5) | 문헌(MongoDB)보다 강한 누출을 우리가 저장함 | B1-4 (m1-astra) |

**우리 시험이 이미 다루는 것(확실):** 빈도 분석(결정 004), 알려진 원문 count 공격 + 제한 전파(US·PC·D010), 회사명 등 저카디널리티 정확 일치 복원(US 98.3%), 검색 관찰 누적·키-only 빈도·로그 꺼짐 조건(AX §2), 다중 시점 일부(AX §3), 길이·위치 배열 통계(AX §4), 개수 시간 채널(AX §5), 위치 이어 붙이기(과제 1). **안 하거나 부분인 것 중 위험 상위는 위 5개**이며, 모두 메모리 시뮬레이션으로 재현 가능하다(B 목록의 한 줄 설계).

### B10. 시험 강화 우선순위 (위험 × 시험 가능성)
1. **선택 원문 삽입(B2-9)** — 시작 단서를 무료로 만들어 0.01–0.1% 구간의 "안전" 결론을 무효화할 수 있음. r9-impl 진행.
2. **위치 이어 붙이기 + 유도 질의(B3-12·16)** — 최종 형식(위치 도장)의 고유 채널. 관찰 조각 수 1,000·10,000, 공격자 유도 질의 순서.
3. **그래프 정합·score attack(B1-2·3)** — 지금 전파가 하한이라는 근거를 수치로.
4. **볼륨·시간 결합(B3-14·B4-17)** — 키 없이 결과 크기·시간만으로 검색어 식별.
5. **공백 수·길이 3중 히스토그램(B1-4)** — m1-astra 정량과 결합.
6. 결합 공격(B5-22)과 LM 완성(B9-31)은 위 결과가 나온 뒤.

| 순위 | 공격(§A) | 우리 구조에 적용 | 저장 형식 변경으로 막을 수 있나 | 어떤 변경·대가 (기존 실측) | 형식 변경 없이 남는 대책 | 확신 |
|---|---|---|---|---|---|---|
| 1 | 선택 원문 주입(A2) | ○ 조각·값 토큰이 행과 무관한 결정적 값이라 공격자가 넣은 행이 곧 라벨 사전 | **부분/전면 가능하나 비쌈.** 전면: 후보 토큰을 행마다 다른 값으로(등장별 꼬리표 + 카운터 = C 방식, 결정 011의 stateful 계열) → 정적 라벨링 0(구성상). 대가: count 317–1,211 ms(28k–68k 꼬리표), 저장 6.7배(890 MB 대 133 MB/10만 행·2칸), 쓰기 9.4 ms/행·잠금 순서·재색인(`bench/results/2026-09-28-mission/`). 부분: 후보 토큰 비트 축소(16 → 12~14)는 결정 004의 방향(14비트 0.00%, 15비트 0.04% vs 16비트 1.19%)과 같지만 **r9-impl 실측으로 미채택**(대가 대비 효과 부족); 토큰 비트는 저장 형식 항목이지만 `reindex`로 나중에 바꿀 수 있어 지금 결정하지 않아도 된다 | 다른 scope엔 불가(토큰 scope 결속, 확실); 가입 검증·한 scope 안 삽입 제한은 운영 | 추정(수치는 r9-impl 시험 후) |
| 2 | 아는 질의 소수·볼륨만으로 질의 복원(A1: Damie 85%, Blackstone 70%, Jigsaw 90%) | ○ 질의 관찰(T4)에서 결과 집합·크기·반복 패턴이 그대로 | **불가.** DB가 정확 판정하는 한 결과 집합·크기는 서버에 보인다(모든 상용 제품 동일, MongoDB USENIX'23). forward privacy(질의마다 새 키)는 고정 키·상태 없음 원칙과 충돌 | 파라미터 로그 금지, `pg_stat_activity` 권한 최소화, 접근 감사(TM §5); count 결과 크기·응답 시간의 볼륨 채널은 남음 | 확실 |
| 3 | 그래프 정합·패턴 마이닝(A3, Bloom n-gram 공격) | ○ 16비트 버킷 = Bloom 비트; 행 안 토큰 동시출현 그래프가 백업에 있음 | **부분.** 비트 축소는 r9-impl 실측으로 미채택(위 1과 같음, `reindex`로 나중 변경 가능); 전면은 등장별 꼬리표(1의 전면과 같음) | 어휘 적은 칸에 부분 검색을 켜지 않기(TM §5) | 추정(시험 B1-3 필요) |
| 4 | 위치 이어 붙이기 + 유도 질의(A4) | ○ 관찰된 조각 키 + 행 salt로 위치 재계산 | **불가(현 설계 안에서).** 위치를 평문으로 두지 않는 변형(도장에 위치를 넣음)은 후보 행마다 위치 전수 시도가 필요해 과제 1b에서 느렸음(`.local/research/task1-m1-astra.md`) | 키 노출 통제(T4 운영 조치)가 유일 | 확실(구조) |
| 5 | 정확 길이·정규화 길이 n·공백 수(A5) | ○ 문헌(MongoDB 16 B 패딩)보다 강한 누출 | **효과 없음(m1-astra 실측).** 길이 패딩은 용량 1.68배가 들어도 공백 수 추측이 98~100%로 그대로였다 — 패딩만으로는 n·도장 수·위치 배열 등 다른 길이 신호가 남아 막지 못한다. 형식 변경 후보에서 제외 | 없음(길이 채널은 남는 누출로 문서화) | 확실(m1-astra 실측, 코디네이터 판정 2026-09-29) |

한 줄 판정: **저장 형식 변경으로 확실히·싸게 막을 수 있는 항목은 없다.** 5(길이·공백 수)는 패딩 실측(용량 1.68배, 공백 추측 98~100% 유지)으로 효과 없음이 확인됐고, 1·3은 "결정적 후보 토큰" 자체가 원인이라 비트 축소(r9-impl 실측으로 미채택, 토큰 비트는 `reindex`로 나중에 변경 가능)나 등장별 꼬리표(결정 011 계열, 큰 대가)로만 다룰 수 있고, 2·4는 검색 관찰 채널의 본질이라 형식 변경으로 막지 못하고 운영 통제만 남는다. 남은 수치 근거는 r9-impl(1)·B1-3(3)의 시험 결과로 확정한다.
